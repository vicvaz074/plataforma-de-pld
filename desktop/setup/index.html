Base de datos central · SQLite

Usa un disco local del servidor. No abras el archivo en dos equipos ni lo pongas en una carpeta de red o sincronizada. Los demás equipos deben usar el modo estación.

Red y acceso desde otros equipos

Para empezar en este equipo, deja el dominio vacío. Para otras estaciones, TI debe configurar un proxy inverso HTTPS hacia el puerto local, conservar el encabezado Host y volver a entrar con el dominio corporativo. La aplicación no expone automáticamente el servidor a la red.

Utiliza entre 11 y 128 caracteres. No hay una clave predeterminada ni se envía por correo.

La base ya tiene cuentas

Conservaremos las cuentas, los permisos y los expedientes. Inicia sesión con tus credenciales existentes.

Necesitas red corporativa o VPN para la primera sesión. Después, una estación autorizada puede consultar información previamente sincronizada y conservar borradores permitidos cifrados cuando se interrumpa la conexión. Los trámites, evidencias y funciones administrativas requieren el servidor.
